## 总评

mommy-chaogu 已经是一个有真实数据、确定性工具、策略卡、记忆、监测、回测模块和多入口体验的
完整投研产品雏形，不是 Demo。它最强的部分是后端能力内核、Agent/MCP 接入、权限边界和对能力
缺口的诚实表达；当前最主要的不足不是“还缺多少模块”，而是尚未用真实用户材料证明最重要的闭环，
以及监测和发布产物仍有会影响用户信任的运行问题。

本次不再用一个 `7.6/10` 同时代表工程成熟度和产品完成度，改为两条独立评分：

| 总评面 | 评分 | 结论 |
|---|---:|---|
| 能力与工程成熟度 | **7.8 / 10** | 核心架构和功能面已经成型，但发布一致性、格式门禁和监测运行语义仍未收口 |
| 真实用户验证完成度 | **6.4 / 10** | 关键路径已实现，但没有真实用户完成并认可“提炼 → 修正 → 保存 → 新会话复用 → 可选监测” |

这两项不能加权成发布结论。工程高分不能抵消用户闭环未验证，用户喜欢某次结果也不能抵消权限、
数据或发行物底线失败。

### 如何理解这些分数

- `8+`：能力已成型，有明确边界和较强工程证据，但不自动等于用户价值已验证。
- `7–8`：能实际使用，仍有一到两个会影响可信度或一致性的现实缺口。
- `6–7`：主路径存在，但用户完成事件、运行承诺或故障恢复尚未被真实证明。
- `N/A`：不是当前产品合同，不用低分制造“必须补齐”的假优先级。

## 四、最值得肯定的地方

1. **核心能力不是样板代码。** 数据、缓存、Agent 工具、策略卡、记忆、组合和多入口都有真实实现。
2. **策略蒸馏方向正确。** 项目没有把用户方法偷换成黑盒自动执行，而是保留来源、原意、限制和确认。
3. **权限边界认真。** 公开行情与个人数据分层，保存与监测分别授权，失败方向倾向 fail-closed。
4. **产品边界诚实。** 不用通用回测、自动交易或高自动化率包装当前能力。
5. **工程基础扎实。** 严格类型、较大离线测试面、数据库分层和真实 MCP 探针足以支撑下一轮用户验收。

## 五、当前最需要补的四个底线

| 优先级 | 缺口 | 为什么现在做 | 对应计划 |
|---:|---|---|---|
| 1 | 发行物与质量基线不一致 | 用户可能安装到与源码不同的前端；已知门禁失败会污染后续判断 | **M0 · 可信基线** |
| 2 | 没有真实策略蒸馏用户闭环 | 这是当前产品主线的关键未知，不解决就无法判断方向是否成立 | **M1 · 真实策略闭环** |
| 3 | 监测运行承诺不够可信 | 用户不知道何时运行、是否陈旧、为什么提醒、如何停止 | **M2 · 可信监测闭环** |
| 4 | 主入口尚未完成干净发布演练 | 工具可见和 doctor 通过不能证明新用户获得第一次价值 | **M3 · 主入口发布演练** |

## 六、下一步：接入改进计划

完整执行说明、Gate、Linear 对应关系和停止规则见
[`IMPROVEMENT-PLAN-2026-09-20.md`](IMPROVEMENT-PLAN-2026-09-20.md)。本评分文档只定义现状和优先级，
不另建第二套路线图。

### MVP

1. **M0 · 可信基线**
   用户验收演示：从干净安装或受支持 Agent 连接进入，看到与当前源码一致的入口和清晰验收范围。
2. **M1 · 真实策略闭环**
   用户验收演示：用自己的材料完成提炼、修正、保存，并在新会话说“按这套方法看 X”得到逐条件结果。
3. **M2 · 可信监测闭环**
   用户验收演示：启用一个受支持监测，看懂运行和触发状态，随后停止并验证不再运行。
4. **M3 · 主入口发布演练**
   用户验收演示：在干净的受支持 Agent 环境理解权限并完成第一次真实有用结果。

### Extensions

- **内置 scheduler / daemon：** 只有 M2 证明用户需要宿主关闭后仍运行才进入。**You can ignore this for now.**
- **Web、TUI、DSH 全入口统一：** 主入口闭环通过后再扩展一致性。**You can ignore this for now.**
- **通用策略回测与 DSL：** 满足数据和方法论进入条件后独立评审。**You can ignore this for now.**
- **非阻塞性架构重构：** 只有现实故障或当前阶段需要时才排期。**You can ignore this for now.**

## 七、一句话结论

**后端和能力内核已经接近 8 分，方向也清楚；但项目下一步不该继续堆能力，而应依次修正可信基线、
完成真实策略闭环、证明监测生命周期，再做一次主入口发布演练。**
