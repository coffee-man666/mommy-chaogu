# 策略卡样例：均线压制与趋势通道观察

> 样例状态：待产品人工评审，不代表已经保存的用户策略，也不代表有效或盈利。
>
> 来源：[`quant/ma-suppression-monitor/README.md`](../../quant/ma-suppression-monitor/README.md)

## 来源与关键原文

来源把方法描述为一个独立的“EMA 云带 / 枢轴通道 / 压制状态机 / 底部评分 / 双引擎”工具箱，
适用于 30 分钟到日线的 OHLC 数据。方法强调 bar 收盘确认、下一根 bar 开盘成交，以及 ATR
归一化。

关键原意：

- 使用 EMA55/EMA89 云带表达趋势与价格相对位置；
- 用 `IDLE → ARMED → ENGAGED → CONFIRMED` 表达一次反弹被压制的过程；
- 结合枢轴/回归通道和 0–100 的底部形态评分；
- 以 `CROSS > RALLY_FADE > BOTTOM_WATCH > TREND_LONG / FREE_FALL` 作为单一警报优先级；
- 方法作者声称全链路无未来函数；这张卡只记录该声明，不代表 mommy-chaogu 主程序已独立验证。

## 原始目标

把一套依赖趋势、反弹压制、通道和底部特征的观察方法保留下来，以后针对指定标的复用；不把它
改写成更容易实现但含义不同的 SMA 规则，也不把一次技术计算包装成历史有效性证明。

## 方法摘要

先用 EMA55/EMA89 与 ATR 判断趋势和价格靠近云带的程度。空头排列下，价格靠近并探入云带后进入
压制观察；若收盘重新跌回云带下沿，记为一次压制确认；若站上云带上沿则失效。与此同时，用通道
位置和底部评分补充观察，并按原方法规定的优先级给出一个当前状态。

## 适用对象与场景

- 股票或 ETF；
- 30 分钟到日线 OHLC 数据；
- bar 收盘后确认状态；
- 作为观察与提醒框架，不自动等同于买卖建议。

## 条件与当前能力边界

| 条件 | 类别 | 当前状态 | 原因 |
|---|---|---|---|
| EMA55 低于 EMA89，且价格进入距云带不超过 1.5 ATR 的区域 | 观察 | 当前不可用 | 独立算法包尚未接入主程序的可靠 OHLC/时间口径；不能用现有 SMA 或肉眼近似替代。 |
| 探入触发区且深度至少 0.2 ATR，状态由 ARMED 进入 ENGAGED | 观察 | 当前不可用 | 需要原状态机逐 bar 运行；主程序当前没有该确定性工具。 |
| ENGAGED 后收盘跌回云带下沿，确认 RALLY_FADE | 进入/观察 | 当前不可用 | 需要原 EMA、ATR 与状态历史共同判断，不能仅凭当前报价推断。 |
| 收盘站上云带上沿，压制观察失效 | 失效 | 需人工判断 | 用户可在使用相同 EMA 口径的图表上人工检查；主程序不自动判断。 |
| 底部评分达到 65，进入 BOTTOM_WATCH | 观察 | 当前不可用 | 需要原四特征权重和崩盘过滤器，尚未接入。 |
| 枢轴/回归通道的位置与触碰关系支持当前判断 | 背景 | 需人工判断 | 主程序能提供部分 K 线，但没有可靠复刻该通道的已接入能力。 |

这张样例没有 `monitor_rule`。现有后台告警只可靠支持价格高于/低于、涨跌幅高于/低于四种精确
阈值；原方法没有给出可以忠实映射成这四类的独立条件。

## 假设、限制与未决问题

- 必须确认实际输入的 OHLC 是否同口径调整、时区/交易日历是否正确；
- 必须保留 bar 收盘确认与下一根 bar 开盘执行的时间语义；
- README 中“跨品种无需人工调参”和“无未来函数”是来源声明，尚未成为主程序承诺；
- 当前可以由 Agent 调用 `research_stock` 提供行情上下文，但不能据此宣称已运行本策略；
- 第一版不做回测、收益统计、参数优化或自动交易。

## 建议给用户的下一步

先确认这张卡是否忠于原方法，以及哪些条件是你实际会使用的。若确认，可以作为“人工方法卡”保存；
未来只有在独立算法的数据输入和主程序可靠接通后，才逐项把“当前不可用”升级为“可自动检查”。
